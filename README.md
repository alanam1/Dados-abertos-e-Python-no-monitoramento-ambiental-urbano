# Dados-abertos-e-Python-no-monitoramento-ambiental-urbano
O repositório em questão mostra o código completo que foi utilizado para fins de metodológicos do artigo "Dados Abertos e Python no Monitoramento Ambiental Urbano: Análise Comparativa de Focos de Calor em Municípios de Mato Grosso. Nele foram realizadas análise e comparações dos focos de calor dos três municípios.
